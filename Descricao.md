Você assumiu o desenvolvimento de uma nova aplicação mobile, cujo propósito é o acompanhamento de linhas de ônibus da capital de São Paulo. O time técnico definiu que o acesso linhas e aos veículos será feito através da Olho Vivo, uma API REST desenvolvida pelo Governo de São Paulo.

Seu objetivo é transformar o Handoff de design em uma aplicação funcional. Você deve implementar as funcionalidades do aplicativo, consumir a API definida e garantir a fidelidade visual e a qualidade do código.

Além disso, será necessário que você utilize, durante seu trabalho, uma folha de papel para criar sua organização de tarefas. Lembre-se de anotar, com clareza, todo seu processo.

Requisitos

Consumir a API do Governo de São Paulo.
Reproduzir fielmente a interface fornecida no Handoff com foco em uma implementação Pixel Perfect.
Adotar uma arquitetura de software consistente e escalável.
Criar componentes reutilizáveis seguindo boas práticas.
Utilizar DocC para documentação de código.
Utilizar GitHub, mantendo um histórico de commits frequentes e explicativos.
Incluir um arquivo README.md com instruções claras sobre o projeto.
Entregáveis

Os seguintes artefatos devem ser entregues ao final do Check-In:

Seu projeto do Xcode comprimido em um .zip.
Documento de planejamento escaneado em PDF.
O link para seu repositório no Github (Não esqueça de convidar os mentores).
